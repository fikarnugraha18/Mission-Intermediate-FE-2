# Museco

One sentence:
Website untuk membuat museum digital pribadi yang bisa dijelajahi orang lain.

Goal:
Membuat pengalaman seperti masuk ke ruang pamer milik seseorang.

Target:
Orang yang suka koleksi, estetika, arsip, dan cerita.

Core Experience:
Create → Arrange → Publish → Explore

Not:
- Marketplace
- Dashboard
- Social media
- E-commerce
